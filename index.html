Document Administration

Kelola metadata dokumen dan struktur cluster. Dashboard ini adalah katalog — file dokumen tetap berada di Microsoft OneDrive.

Catatan penting mengenai penyimpanan data. Dashboard ini adalah berkas HTML statis tanpa backend. Perubahan yang Anda lakukan pada tab Administration disimpan di penyimpanan lokal browser ini (localStorage) sehingga hanya terlihat di perangkat & browser yang sama — bukan di server dan bukan untuk semua pengguna. Untuk penggunaan produksi, hubungkan lapisan data ke backend seperti SharePoint List, Microsoft Dataverse, atau API kampus. Gunakan Export JSON untuk memindahkan data antar perangkat atau menyimpannya sebagai arsip.
